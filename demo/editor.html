    REVIEW BEFORE RELEASE

    GitHub is the source of truth.

    Open GitHub upload
    1. Download and extract the change ZIP.
    2. Upload its three JSON files to the repository's config folder using your own GitHub sign-in.
    3. Select “Create a new branch for this commit and start a pull request”.
    4. Review the validation and CI checks, then merge. The Pages workflow publishes the new configuration.

    Network transparency

    Editing and validation happen in your browser. The online shell loads Mightora shared branding. Loading published configuration is a separate, deliberate request. The offline editor makes no application network requests.

    Resource Timing is a partial view and is not a security audit.

    Press F12 (or your browser's Developer Tools shortcut), open Network, enable Preserve log and reload. Inspect requests, cookies and storage there. On-screen results may omit blocked requests, other frames and browser activity.
